# Herdr Alt-Tab

A Herdr plugin that moves focus between panes in most-recently-used order, the way Alt+Tab moves between windows.

## Language

**Cycle**:
One run of Alt+Tab presses, from the first press until Alt comes up or the user stops pressing. Panes the Cycle passes through do not change their place in recency order; only the pane it ends on does.
_Avoid_: Session
